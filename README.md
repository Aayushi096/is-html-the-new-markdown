# Is HTML the new Markdown?

An interactive, HTML version of my LinkedIn carousel. Same post, rebuilt for people instead of parsers.

**Live:** https://aayushi096.github.io/is-html-the-new-markdown/

What you can do on the page:

- Edit the Markdown on slide 2 and watch the rendered side follow
- Tap the cards on slide 4 to run each HTML tag
- See a live token count (Markdown vs HTML) on slide 5, measured from your own edits
- Drag the "polish" slider on slide 7, then check whether the answer is actually right
- Flip any slide to its raw Markdown with the switch under the card (or press `M`)

It's a single `index.html` file with no build step and no dependencies apart from Google Fonts, served by GitHub Pages.
