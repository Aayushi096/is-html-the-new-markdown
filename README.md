# Is HTML the new Markdown?

An interactive, HTML version of my LinkedIn post. Same story, rebuilt for people instead of parsers.

**Live:** https://aayushi096.github.io/is-html-the-new-markdown/

What's on the page:

1. The hook: you scrolled past my text post
2. The irony: 2004 "stop typing HTML" vs 2026 "generate an entire HTML experience"
3. So who put HTML back in the group chat? A timeline from Gruber to Shihipar
4. The spark: Thariq Shihipar's "hundred lines" quote, plus a 120-line file to try reading
5. A document you can break: the same spec as Markdown and as a clickable change-impact explorer
6. Why now: a year slider showing how building got cheap while attention didn't
7. A format picker: which format suits a prompt, README, data contract, incident, architecture review or PR
8. The catch, in four points
9. A copyable prompt for your next review
10. The plot twist, with a poll
11. Sources

Flip the whole page to raw Markdown with the switch in the top bar (or press `M`).

It's a single `index.html` file with no build step and no dependencies apart from Google Fonts, served by GitHub Pages.
