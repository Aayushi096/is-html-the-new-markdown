# Is HTML the new Markdown?

An interactive, HTML version of my LinkedIn post. Same story, rebuilt for people instead of parsers.

**Live:** https://aayushi096.github.io/is-html-the-new-markdown/

What's on the page:

- HTML is the new Markdown? Well, that's a plot twist.
1. The problem: AI does the work in seconds, then hands you a 500-line scroll
2. A 22-year plot twist: 2004 "stop typing HTML" vs 2026 "generate an entire HTML experience"
3. So who put HTML back in the group chat? The story in one table, with year pills
4. Why now: a year slider showing building got cheap while review time didn't
5. The spark: Thariq Shihipar's "hundred lines" quote, plus a 120-line file to try reading
6. A document you can break: the same spec as Markdown and as a clickable change-impact explorer
7. Which format: a 2×2 of who reads it and what they need to do with it
8. The catch, in four points
9. A copyable prompt for your next review
10. The plot twist, with a poll
- Sources

Flip the whole page to raw Markdown with the switch in the top bar (or press `M`).

It's a single `index.html` file with no build step and no dependencies apart from Google Fonts, served by GitHub Pages.
